# Halloween Hackathon Assets

This directory contains Halloween-themed images for the Halloween Hackathon 2025 landing page.

## Required Images

### Hero Section
- `halloween-hero-bg.jpg` - Dark Halloween background with pumpkins, bats, and spooky atmosphere
- `halloween-coding.jpg` - Developer working on spooky code with Halloween decorations

### Section Backgrounds  
- `pumpkin-code.jpg` - Carved pumpkins with code symbols
- `spooky-laptop.jpg` - Laptop with Halloween-themed code editor
- `halloween-workspace.jpg` - Developer workspace decorated for Halloween

### Icons and Graphics
- `halloween-hackathon-og.png` - Open Graph image for social sharing
- `spooky-icons/` - Directory with Halloween-themed tech icons

## Image Specifications

- **Hero images**: 1920x1080px minimum, optimized for web
- **Section images**: 1200x800px, optimized for web  
- **OG image**: 1200x630px for social media sharing
- **Format**: JPG for photos, PNG for graphics with transparency
- **Optimization**: Use WebP format when possible for better performance

## Usage

These images are used throughout the Halloween Hackathon landing page to create an immersive spooky atmosphere while maintaining the professional look of the Soapbox brand.

## Stock Photo Sources

All images should be:
- Royalty-free or Creative Commons licensed
- High quality and professional
- Relevant to both Halloween themes and coding/technology
- Optimized for web performance

## Color Palette

The Halloween theme uses:
- Orange (#ea580c, #f97316) - Primary Halloween color
- Purple (#7c3aed, #8b5cf6) - Secondary spooky color  
- Red (#dc2626, #ef4444) - Accent color
- Black/Dark gray - Background and text
- White - Text and highlights
