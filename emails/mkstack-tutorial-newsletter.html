What You'll Learn

MKStack makes it easy for anyone to build apps on the Nostr protocol, no coding experience required. Just describe your idea in plain language, and the system takes care of the rest, setting up your app, connecting it to the Nostr network, and generating the code for you.

This comprehensive tutorial covers everything from installation to deployment, showing you how to use Stacks, MKStack, and the AI agent Dork to create fully functional Nostr applications through simple conversational prompts.

Getting Started is Simple

Follow these basic steps to start building your first Nostr app

1

Install Node.js

Download and install Node.js from nodejs.org. Easy installers available for Windows, Mac, and Linux.

2

Install Stacks

Learn more about MKStack and follow the instructions to install Stacks and the MKStack template.

3

Configure AI Provider

Choose your AI provider (OpenRouter, Routstr, or PayPerQ) and enter your API key to activate Dork.

4

Start Vibe Coding

Describe your app idea in natural language to Dork, and watch as it builds your Nostr application.
