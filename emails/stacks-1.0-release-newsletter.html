What's New in Stacks 1.0?

Multiple AI Providers

Be your own OpenRouter

Easily configure and switch between multiple AI providers. Use different providers for different models, or even your own custom models. Store settings for OpenRouter, PayPerQ, and more.

Switch between providers instantly with the new provider management system

  • Configure multiple AI providers at once
  • Per-project AI settings that remember your preferences
  • Access models with simple slash notation (e.g., openai/gpt-4o)
  • Quick model switching with recent models suggestions
⚡

Slash Commands

Power at your fingertips

Type / in any Stacks agent session to access all available commands. Change models, temperature, and more—mid-prompt!

Type / to access all commands in your Stacks agent session

  • Switch models or providers instantly (/model, /providers)
  • List available tools (/tools)
  • Show or load chat history (/history, /load)
  • Adjust temperature (/temperature)
  • Type /help or / to see all commands
💾

AI Chat History

Never lose your flow

Every chat with your AI agent is now saved in a .ai folder in your project—just like .git. Reload any previous session, pick up where you left off, or review your progress at any time.

All your AI chat sessions are saved and reloadable in Stacks 1.0

  • All AI sessions saved in .ai folder (inspired by .git)
  • Each project keeps its own settings and history
  • Reload any previous session to continue where you left off
  • Review your development progress over time
🚀

Easy Upgrade Process

Get started in minutes

Upgrading to Stacks 1.0 is simple! Just run stacks upgrade to get started. Note: provider config will reset for a smoother setup experience.

How to Upgrade:

  1. Update your CLI: npm install -g @getstacks/stacks
  2. In your project folder, run: stacks upgrade
  3. Re-enter your provider config (it's easier than ever!)
  4. Start building: stacks agent

Upgrading to Stacks 1.0 is just one command away

What is Stacks?

Stacks is a decentralized AI template-sharing platform built on Nostr, designed specifically to jumpstart development using templates and tools alongside LLMs.

Featured stacks. Explore more on getstacks.dev

Anyone can publish a stack, which allows others to use their templates as a starting point for AI-first coding. MKstack, a tool for building Nostr apps with AI, is one such stack!
