Any AI Provider

Maximum flexibility and choice

Unlike other tools that lock you into their AI models, Shakespeare Act 2 supports any AI provider. Bring your own API keys for OpenAI, Anthropic, Routstr, PayPerQ, and more, run local models, or use our pay-per-use Shakespeare AI services.

  • OpenAI, Anthropic, Claude, GPT-4, Gemini support
  • Local AI models (Llama, CodeLlama, etc.)
  • OpenRouter, PayPerQ, Z.ai, and 40+ providers
  • Custom API endpoint connections
  • No vendor lock-in or restrictions

Complete Development Environment

Professional tools in your browser

Act 2 provides a complete development environment in the browser. Web text editor, file uploads, terminal commands in chat, live preview, Git integration, and full project export. No downloads required.

  • Built-in code editor with syntax highlighting
  • File upload and asset management
  • Virtual Linux environment with CLI tools
  • Real-time preview with hot reload
  • Complete project export capabilities

True Decentralization

Your files, your control

All project files are stored locally in your browser using IndexedDB with LightningFS. Git operations run entirely client-side with isomorphic-git. No servers, no data collection, complete privacy and control.

  • Local file storage with IndexedDB
  • Client-side Git operations
  • No data collection or tracking
  • Complete project privacy
  • Works offline after initial load

Git Integration & Project Import

Import from any repository and track all changes

Shakespeare Act 2 includes complete Git integration with the ability to import existing projects from GitHub, GitLab, or any Git provider. All Git operations run client-side with no servers involved.

Git & Import Features:

  • Import projects from any Git repository URL
  • Client-side Git operations with isomorphic-git
  • Push and pull to GitHub, GitLab, and custom providers
  • Automatic commit tracking and version history
  • Support for Nostr Git URLs (nostr://)
  • Complete project export with Git history
